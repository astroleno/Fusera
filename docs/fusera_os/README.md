## What This Folder Solves

The goal of this folder is to prevent Fusera from being treated as only an AI page generator.

It defines Fusera as a repeatable operating system for:

- collecting overseas market and user signals
- converting signals into page strategy
- generating strong landing pages
- gating quality before release
- measuring outcomes
- writing reusable learning back into memory

## Current P0 Focus

For the current phase, this folder should help the team deliver only three top-level outcomes:

| Focus Area | Why It Matters |
|---|---|
| `research -> brief -> release` loop | proves Fusera can reliably ship one strong page end to end |
| Research DB and memory | prevents repeated rediscovery and improves future runs |
| Design system and tone pack | prevents brand drift and generic output |
