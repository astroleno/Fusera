# Landing Pattern Recipes

Use these recipes before opening long prompt files. They distill reusable patterns from the 71 prompt corpus and keep implementation agents from copying unrelated dependencies, brands, or full-page code.

## Recipes

- `video_hero.md`: full-screen video/HLS hero with readable copy and fallback states.
- `scroll_story.md`: scroll-linked landing page sections, parallax, scrub, and pinning boundaries.
- `css_3d_card.md`: CSS perspective and 2.5D interaction without WebGL.
- `liquid_glass_saas.md`: glass, dark cinematic SaaS/AI hero composition.
- `asset_fallbacks.md`: external media, font, poster, and licensing fallbacks.
- `gsap_scrolltrigger.md`: when GSAP is justified and how to contain it.
- `three_product_canvas.md`: when real Three.js/WebGL is justified and how to keep it safe.
- `prompt_reuse_discipline.md`: how to reuse prompt references without copying conflicts.

## Selection

Pick recipes from the Route Card:

- `video_background` -> `video_hero.md`
- `scroll_parallax` -> `scroll_story.md`
- `css_3d` -> `css_3d_card.md`
- `liquid_glass` + SaaS/AI -> `liquid_glass_saas.md`
- any external media/font/model -> `asset_fallbacks.md`
- explicit GSAP/ScrollTrigger -> `gsap_scrolltrigger.md`
- explicit Three.js/WebGL/GLB/shader/particles -> `three_product_canvas.md`
