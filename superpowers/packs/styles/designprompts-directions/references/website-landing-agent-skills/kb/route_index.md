## 选择原则

1. 先选一个 primary prompt：行业/业务最接近，并且不是 `stub_or_empty`。
2. 再选 1–3 个 supporting prompts：分别补足视觉风格、动效模式、页面结构。
3. 不要把多个 prompt 的所有要求硬拼到一个页面；只抽取可复用 pattern。
4. 外链视频、字体和图片必须进入 asset manifest，并提供降级方案。
5. 默认用 React + TypeScript + Vite + Tailwind；只有 prompt 明确要求时才引入额外依赖。
