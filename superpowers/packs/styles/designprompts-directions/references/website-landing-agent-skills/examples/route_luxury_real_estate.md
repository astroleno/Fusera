# Example: Luxury real estate landing

Brief:

> 做一个高端房地产 landing page，奢华极简、全屏视觉、滚动展示项目卖点，移动端也要好看。

Expected route logic:

- Industry: `real_estate_architecture`
- Visual: `luxury_minimal`, `dark_cinematic` or `clean_white`
- Interaction: `video_background` or `scroll_parallax`
- Scope: multi-section landing

After routing, use `site-brief-to-spec` to replace prompt-specific property names, images, and sales claims with the user's actual project information.
